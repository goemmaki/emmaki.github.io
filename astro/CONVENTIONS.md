# Astro conventions

- Use design tokens from `docs/design-system/` and `globals.css` only. Do not introduce raw color, spacing, type, timing, or motion values.
- Render static markup in `.astro` files. Put behavior in vanilla TypeScript `<script>`s; do not add React or other framework islands.
- The first paint must already look like the settled page. Do not build visible DOM, insert text, or start textures in deferred scripts when HTML, CSS, or a tiny inline script immediately after the element can produce it.
- Preserve algorithms and timings when porting behavior. Honor reduced motion.
- Keep shared code in root `src/` until Next is retired. Never fork it without a Decision Log entry in the migration ExecPlan.
- Run package commands as `pnpm --dir astro --ignore-workspace ...` so pnpm does not select the root workspace.
- Compare changes with `node astro/scripts/parity.mjs`. It captures both sites for each route, theme, and viewport, records metadata, geometry, errors, and JavaScript bytes, and compares full-page pixels. A pass means the recorded nonvolatile metadata, geometry, errors, and screenshot pixels match within the 0.5% raster budget; JS byte totals are informational because the bundles differ by design. On mobile only, document height may differ by up to the previously observed 6 px and is reported as an expected delta. The script masks only the volatile selectors declared at its top. Dev servers can report HMR/toolbar errors, so use `REF=http://127.0.0.1:3006 NEW=http://127.0.0.1:3005` to compare production exports when these servers are available. `INJECT_CSS` applies a deliberate style change to Astro only for hostile calibration checks. Use `FRAMES=1 BROWSER=chromium` for an acknowledged CDP screencast and per-frame changed-pixel table.
- Calibration evidence (2026-11-01): Firefox production comparison passed all 12 Home, Brands, and article cases (dark/light, 1440×900/390×844). A 1 px `main` translation and an explicit red foreground/background injection both failed as expected. Hue rotation alone was not a strong color probe on the mostly monochrome Brands capture; use a change that visibly affects a substantial region.
- Run checks through `run-check -- <command>` and judge the final `run-check: PASS|FAIL` line.
