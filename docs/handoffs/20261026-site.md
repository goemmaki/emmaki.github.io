## Watch-outs and gotchas

- **The cover photo is not in Git.** `public/blog/blog-photo.jpg` is a dev-only file excluded through `.git/info/exclude`. A fresh worktree has no copy and the cover crashes with "drawImage … broken state" (this happened 2026-10-26). Copy it from `~/worktrees/goemmaki/site-shell-20261023/public/blog/`.
- **Never merge to `main`**: GitHub Pages publishes it raw. "Merge" means fast-forward `design/foundation`.
- **Dev servers:**
  - The owner's dev server on 3001 serves the site-shell worktree, which is pre-refactor.
  - The refactor worktree is viewed with `pnpm dev -p 3002`.
  - Give the owner `http://192.168.20.5:<port>/...` URLs. `localhost` on their PC has been unreliable since 2026-10-25, probably because of Antigravity's port forward.
- **Visual regression harness:** `runtime/visual/` in the refactor worktree (`shoot.cjs`, `serve.py`, `compare.py`). It is ignored scratch, so copy it out before deleting the worktree if you want to keep it.
  - Playwright comes from the npx cache: `NODE_PATH=/home/emma/.npm/_npx/e41f203b7505f1fb/node_modules`, using `/usr/bin/google-chrome`.
  - Each served `out` copy needs the cover photo.
- **Base UI menus:** keep `modal={false}` on `Menu.Root` in `post-tools.tsx`, or the page stops scrolling.
- **Tailwind v4:** `outline-none` sets `outline-style: none`, so a focus-visible ring needs `focus-visible:outline-solid`.
- **The TOC throws** if a heading id is missing; ids come from `headingId()` in `posts.ts`.
- **Static export:** every post must appear in `generateStaticParams`.
