# Site development history: 2026-09-24 to 2026-10-26

This is a dated reconstruction from Git history, the listed Claude Code transcripts, repository handoffs/design records, and the permitted Codex audit reports. Commits establish code states; transcript dates establish direction and feedback where recorded. Claims marked **inferred** are conclusions from that evidence. Commit IDs are abbreviated to 8 characters unless needed to disambiguate.

## Starting point

On 2026-09-24, the repository contained only a README (`9ca3f649`). On 2026-09-25, it became a small Vite/React portfolio scaffold, with an animated wordmark and several logo iterations (`db933793` through `e54966e4`). A handwriting-mask logo attempt was reverted because it broke the mark (`d055d75d`, `0d25f122`, `e54966e4`). This was a prototype, not the current site.

On 2026-09-27, the Vite site was removed (`80c2f284`), Next.js was bootstrapped (`418267ad`), and the Luma/shadcn and Motion foundation was added (`309b3117`). The canonical Emmaki design-system documents were added the same day (`313f8ddb`). The first designed site pass landed on 2026-09-28 (`2d4ae409`); Fiverr-specific visual direction followed on 2026-09-29 (`49c7c64b`). No site-code commits appear from 2026-09-30 through 2026-10-22 in the supplied repository history (**inferred** from `git log --all`, latest preceding site commit `49c7c64b`). This does not establish that no off-repository design work occurred.

The current design push began on 2026-10-23 with a new site-shell branch. Placeholder pages and an earlier composition were removed, and a new header, slide-out menu, footer, and initial routes were built (`2e49bd4e`, `548c88b2`, `f7d09f57`). The site was therefore developed in several periods from September 24 through October 26; the commits do not support describing it as built in two days.

### 2026-10-24

## Light and dark themes

The September 25 prototype introduced yellow accents and a shrinking sticky logo (`9f4e48d4`). The September 27 canonical system then established a dark-first neutral brand, with color as restrained signal (`313f8ddb`). On October 23–24, the shell and hero were tuned in both themes; the hero sparkle hue was darkened on light backgrounds and headline/wordmark color use was corrected (`fd74534f`, `0f620c5e`, `5ead88a7`).

The blog body uses gray copy and white/maximum-ink headings in dark mode, with corresponding neutral roles in light mode (`7a2cfd37`, `b9f3dc10`). The footer tried theme-dependent spotlight colors and later settled on the selected dither/wordmark treatment (`09611ef7` through `e84b157a`).

The cover was intentionally not made identical in mood: light mode keeps a color photo and no flashlight; dark mode is grayscale with the moving flashlight. Both share the scroll structure and contrast requirements (`74ecbf7f`, `88626dd2`, `20c7b33c`). The owner chose white cover text on a dark shade for light mode after the black title failed against variable photo pixels (cover audit and transcript 2026-10-26).
